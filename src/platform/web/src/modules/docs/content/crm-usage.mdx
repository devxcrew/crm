# Use CRM

CRM reads and writes live Enquiry records on the connected Frappe site. Your account must have verified Frappe credentials.

## Create an enquiry

1. Select **New enquiry** above the CRM menu.
2. Enter a 10-digit mobile number.
3. Select **Search** or press Enter.
4. Review the latest enquiry when one exists.
5. Select an existing Customer.
6. Enter the enquiry message and required details.
7. Save the enquiry.

The mobile field shows a green ring after you enter 10 digits. Recent searches stay in the current browser session.

## Use the CRM lists

Use **My Job** for enquiries assigned to you. Use **My Calls** for enquiries that you created.

Select a row to open its details. Use the row action menu for actions that your role allows.

Won and Lost enquiries do not appear in the active list. Select another status filter when you need closed records.

## Update an enquiry

Open an enquiry and update Status, List in, Priority, or Assigned to. CRM keeps Status and List in as separate Frappe fields.

Use **Follow** in List in when the enquiry needs follow-up. Do not use Follow as a Status value.

## Add work records

Open the enquiry details to add comments, jobs, estimates, quotations, schedules, or attachments. The available tabs depend on your role.

## When access changes

Sign out and sign in again after an administrator changes your role or permissions. The new session receives the updated access token.
